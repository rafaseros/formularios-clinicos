# Changelog — PGB-F014-B Reporte de Enfermería

## v1.1 — 2026-05-05

**Cambios** (observación de la clínica):

- Se reemplazaron las 8 filas con divisiones horizontales por una única fila con guías horizontales para escritura manual. Las divisiones verticales (Fecha / Hora / Nota / Firma) se mantienen.
- El campo `Hoja: 1 / 1` del header pasa a `Hoja: __ / __` para llenado manual al archivar el expediente.
- El `Página 1 de 1` del footer pasa a `Página __ de __` por la misma razón.

**Razón**: las evoluciones que registra el equipo médico son extensas y no caben cómodamente en celdas de 2 cm. La numeración de hoja se gestiona manualmente al archivar.

## v1.0 — Versión inicial

Versión inicial conforme a normativa SEDES (D.S. 28562, R.M. 0090/2008).
